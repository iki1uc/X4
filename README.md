# X4 – Systemmodul

X4 ist ein minimales Modul bestehend aus HTML‑Kerndateien und zwei Sequenzdateien.
Es dient als Basis für weitere Systemkomponenten.

## Dateien

- HTML.index   – Hauptkern
- index.html   – Startpunkt
- inde.html    – Zweiter Startpunkt
- t            – Sequenzdatei
- T            – Sequenzdatei (Variante)
- README.md    – Dokumentation

## Zweck

X4 stellt eine einfache Struktur bereit, die für Tests, Module und Erweiterungen
verwendet werden kann. Es enthält keine Logik und keine Abhängigkeiten.
